# 版の履歴と残っていること

## 版の履歴

### アプリ・ファームウェア

| 版 | 主な変更 |
|---|---|
| 1.3.2 | 一瞬の爆音の診断：スライダーの値が大きく跳ねたらログに残す。つないだ直後の行・本数の合わない行を使わない |
| 1.3.1 | 一時停止・終了で全体の音量を戻さない（止めた瞬間に急に大音量になるのを防ぐ） |
| 1.3.0 | 言語設定（日本語 / English）、Mac 版 |
| 1.2.0 | **最初の公開版**。プロファイル（自動切り替え・ショートカット）、音量を飛ばさない（ピックアップ）、一時停止で元に戻す、一時停止のショートカット、ゲーム（全画面のアプリ）、OBS 連携、LED 連携と光り方の設定、音量の変わり方、スライダーの端の位置合わせ、コントローラーの ID と別の USB の口に差した時の探し直し（ファームウェア 1.3） |
| 1.1.0 | 一時停止、スライダーごとの設定（反転・最大音量・100% になる位置）、アプリを一覧から選ぶ（非公開） |
| 1.0.0 | 最初の版（非公開） |

ファームウェアの zip はアプリの版の名前で作ります。中身は 1.2.0 から変わっていません。

### Chrome 拡張機能

| 版 | 主な変更 |
|---|---|
| 1.5.0 | 音が鳴ったタブを空いている番号へ自動で割り当てる（ポップアップでオン。方式 Y の時も、自動で割り当てたタブは方式 X で変える） |
| 1.4.1 | 方式 X（「今使っているアプリ」で Chrome のタブを下げる時も）で、YouTube の動画が始まる時などに一瞬元の音量で鳴るのを直す。下げたタブを再読み込みしたらかけ直す |
| 1.4.0 | ポップアップ・右クリックメニューを deej-tab の言語に合わせる |
| 1.3.1 | 最初の公開版（アプリ 1.2.0 と一緒に公開） |
| 1.3.0 | Alt+Shift+A で空いている番号へ順に割り当て |
| 1.2.0 | 番号のショートカット・右クリックメニュー・バッジ、割り当て済みの番号と音の大きさを deej-tab へ送る |
| 1.1.0 | 一時停止、100% 超えとリミッター |
| 1.0.0 | 最初の版 |
