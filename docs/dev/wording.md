# 画面の文言のルール

設定画面・トレイ・拡張機能に出す言葉は、初めて使う人が読んでわかる言葉にします。新しい文言もこれに合わせます。

## 言葉の選び方

- 本体は「コントローラー」と呼ぶ（「デバイス」「Nano」「実機」は使わない）。ファームウェアの書き込みなど技術的な説明だけ「Nano」
- 「既定」→「初期設定」、「〜した時」→「〜したとき」（時間・同時・起動時などの熟語はそのまま）、「繋ぐ」→「つなぐ」
- 専門用語を出さない

| 中身 | 画面の言葉 |
|---|---|
| 追従（glide） | 音量の変わり方（すぐ／なめらか／ゆっくり／とてもゆっくり） |
| ピックアップ | 音量を飛ばさない |
| スロット（拡張機能） | 番号 |
| ノイズ除去 | 揺れの抑え |
| 比例 | 自動 |

## 割り当て先の名前

| 割り当て先 | 画面の名前 |
|---|---|
| `master` / `system` / `mic` | 全体音量・システム音・マイク |
| `deej.current` | 今使っているアプリ |
| `deej.game` | ゲーム（全画面のアプリ） |
| `deej.unmapped` | そのほかのアプリ |
| `tab.N` | Chrome タブ N |
| `obs:…` | OBS の音声ソース |

## LED

- 設定の見出しは「LED で知らせること」（なし／状態／状態と音の大きさ）と「LED の光り方」（操作していないとき／起動したとき／操作したとき）
- 数値の名前は、選んでいる光り方に合わせて変える（例：往復する光 →「光の点の明るさ」「光の点が往復する速さ」。`ui.html` の `LED_MAIN`）
- 光り方の名前（`leds.py`）
  - 操作していないとき：点灯したまま・呼吸・流れる波・きらめき・鼓動・往復する光・スライダーの位置に合わせる
  - 起動したとき：左から右へ流れる・中央から広がる・全体がふわっと点く・左右に往復する
  - 操作したとき：明るく光る・波紋（端まで広がる）・スライダーの位置に合わせる

## 拡張機能

- 方式の名前は「タブの音をまとめて調整」（キャプチャ）と「ページ内の動画の音量を変える」

## 書き方

- 説明文（`<small>`）は文末に「。」を付けない。2 文以上は「。」で区切る
- 設定画面に文言を足したら、`ui.html` の `I18N_EN` に英語も足す（Mac 向けの言い換えは `MAC_TEXT`）
