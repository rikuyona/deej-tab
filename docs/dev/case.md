# ケースとツマミ（`case/case.py`）

1 本のスクリプトでケース・ツマミ・試し刷り用の部品を作ります。寸法はファイル先頭の設定で変えられ、出力は `case/out/` です。部品とケースの干渉も確かめます。配布用の STL は [MakerWorld](https://makerworld.com/models/3382344) に載せています。基板版のケース（`case.py --pcb`）は [pcb.md](pcb.md) を見てください。

| 出力 | 中身 |
|---|---|
| `top_plate.stl` | 天板（一枚もの） |
| `bottom_case.stl` | 底ケース |
| `nano_clip.stl` | Nano の押さえ |
| `cap_core.stl` + `cap_shell.stl` | スライダーのツマミ（芯と外殻の 2 色） |
| `knob_body.stl` + `knob_line.stl` | ノブ（本体と指示線の 2 色） |
| `fit_test.stl`・`knob_fit_test.stl` | はめ合いの試し刷り |
| `viewer.html` | 部品を入れた状態を回して見られるページ |
| `*_section.png`・`*_drawing.png` | 断面図・図面 |

## 前提

- プリンター：Bambu Lab A1 mini＋AMS（ベッド 180×180×180、多色刷り）
- フィラメント（Bambu PLA Matte、`PART_FILAMENT`）：天板＝アイボリーホワイト、底ケース＝アッシュグレー、ツマミの外殻・ノブ＝チャコール、ツマミの芯・ノブの指示線＝アイボリー
- 見た目：ミニマル・インダストリアル（キーボードの Lofree Flow に寄せた）。書体は Bahnschrift

## 外形と配置

- 外形 126×126、高さは手前 16.2mm・奥 23.5mm（傾き 3.3°）。パネル・底は 2.0mm。角の丸み R8、上の縁は 45° 面取りから丸みにつなぐ
  - 手前 13.4mm にしたかったが、スライダー（パネルの下 10.5mm＋配線 2.5mm）が入らないので、差 7.3mm を保って最低限まで上げた
- スライダー 5 本を 22mm 間隔（X = 19・41・63・85・107、中心 Y = 51）、ノブは左奥（19, 106）、Nano は X = 90（スライダー 4・5 の奥端の下）で USB-C を奥に出す
- Nano の位置は、端子の下の配線の余裕 2.5mm を取ったうえで、いちばんすき間が残る所を総当たりで選んだ（残り 0.5mm）
- 部品は実物寄りにモデル化しています（スライダーは本体 7mm＋両端の端子、Nano は基板・USB-C・表裏の部品・端子列の配線）。干渉チェックには端子の下の配線の余裕と、ツマミが動く範囲も含めます

## 天板（`top_plate.stl`）

厚さ 10.3mm の詰まった一枚板で、**表を上にして刷ります**。サポートは外側の帯の下（分割溝の所、幅約 2.2mm の張り出し）だけ「ビルドプレートのみ」。

- 厚さ ＝ パネル 2＋スライダー本体 7＋爪の返しのすき間 0.2＋返し 1.1。裏は平らでプレートに接します
- パネル上面から 5mm（`BAND`）の所に側面一周の分割溝（高さ 0.8・深さ 0.5）。ここで天板と底ケースが分かれ、合わせ目は溝に隠れます。溝より下は底ケースの壁の内側に入る差し込み（すき間 `FIT` 0.3）
- 裏のくぼみ（貫通）：スライダー本体 9.6×75.6（`POCKET_FIT` 0.3）、ボリューム Φ18＋端子の逃げ。M2 の皿ネジ穴も残します
- **スライダーの爪**（`SLIDER_CLAW`）：くぼみの長い壁を U 字に切り離した板（厚さ 1.2・幅 6）を、本体の中心から前後 ±22 に左右 2 つずつ。返しが本体の下に 0.6 掛かり、裏から押し込むと斜面で外へ逃げます。本体 7.2mm に掛かる位置（どうせ M2 でも留めるので、短い個体は気にしない）
- 目盛り（各スライダーの右に 11 本、0・50・100% は長い）・番号 1〜5・ノブの目盛り（300°）は**彫り**（深さ 0.4、`MARK_DEPTH`）。刷ったあとに塗料（水性アクリル・スミ入れ塗料・ポスカなど。ラッカー系は PLA を傷める）を流し込んで拭き取ります
  - 多色で刷る方法はどれもきれいに出なかった（彫って別の色で埋める形はスライサーが底に床を作らず色がインフィルに落ちた／表に盛る形は質が低かった）。パネル面を下にする案はプレートがテクスチャ付きなので不可
  - 線幅はどれも約 0.9mm（0.4 ノズルで 2 本ちょうど。目盛り `TICK`、文字は輪郭を 0.2 太らせる `TEXT_GROW`、高さ 3.8 `LABEL_H`）。0.8 の線や 0.6 の文字の画は汚くなった
  - 文字の塗り方は NonZero（フォント本来）。EvenOdd だと「4」の交差に穴が空いた
- 0.08mm の層で刷ると天面にインフィルの模様が透けます（ピローイング）。疎インフィル 100% か、上部シェル 1.0mm 以上にします

## 底ケース（`bottom_case.stl`）

底＋分割溝より下の側面、四隅の柱、Nano の台、USB-C の穴、スナップの溝。底を下にしてそのまま刷ります。底の下の縁は 1.2 面取り（浮いて見える）。

### 天板と底ケースの留め方

- **スナップフィット**（`SNAP`）：差し込みの各辺の中央（長さ 40）に台形の出っ張り（0.7 出る、先の平ら 0.4、両側 45°）、底ケースの壁の内側に溝（深さ 0.6、長さ 42）
  - はまった時に出っ張りの上の斜面が溝の上の斜面にぴったり触れる寸法にすると、ガタが出ません。溝の下側は 0.3・奥は 0.2 のすき間
  - 手前・奥の辺に置く形は、パネルの傾きで深さ 7.5 の所が前後に 0.43 ずれるので戻します（`snap_bars` の k）
- **四隅の柱**：底ケースから天板の裏の 0.2 下まで立てます（`BOSS_GAP`。締めた力が分割面にかかる）。足りなければ M3×8（なべ / キャップ）で、底の座ぐり（Φ6.4）から天板の裏へ締められます（かかり 4.9）。傾きの分は座ぐりの深さで吸収（`screw_seat_z`）

## Nano の押さえ（`nano_clip.stl`）

USB の抜き挿しで基板が奥を支点に傾き、手前が浮いたので足した部品です。原因は、台が奥 31mm だけで手前を支えるものがなかったことと、基板が実測で薄く（1.1mm）USB-C が穴の下の縁に当たって奥だけ持ち上がったことでした。

- 基板は台より 0.45 上（`nano_seat_z()`、USB-C が穴の中で上下に少し空く高さ）に、押さえと USB-C の穴で水平に固定します
- 形は **1 つの箱から「止めが入るくぼみ」と「基板の手前の端が入るすき間（高さ 1.15）」を削っただけ**。すき間の上が基板を押さえ、下が裏を受け、左右が角を挟みます。部品を足し合わせると細かいすき間や段ができたので、削る形にしました
- 基板の端から 4.6mm まで全幅で押さえます（ICSP と 1 本目の端子は使わないので押さえてよい）
- 底ケースの止め（板）の厚さは 1.75mm（`NANO_STOP_T`。1.6 で作ったら刷り上がりが細かった）
- 押さえのくぼみと止めのすき間は、前後・横とも片側 0.05（`NANO_CLIP` の最初の値）。0.2 では、止めの板が刷り上がりで約 0.2 薄く出るぶん遊んでスカスカだった。ゆるいと直せないが、きつければ削って合わせられるので、きつめにしている
- 手前の面を下に立てて刷ります。サポートなし
- 組み立て：押さえを基板の手前の端に差してから、一緒にケースへ下ろします（先に接着すると基板が入らない）
- 実物で組んで、はめ合いを確かめ済み

## スライダーのツマミ（`cap_core` + `cap_shell`）

秋月の CS-52 と同じ 2 色構成です。乳白の芯（レバーの穴と指示線の板）に黒い外殻（厚さ 1.2、前後 2 つ）をかぶせ、レバーの LED の光が芯を通って上面と両側面の白い線が光ります。

- 形：横から見て、下の帯（高さ 2.2）から両端が外へふくらむ円弧で細い山へ、上面は山から山への大きな凹んだ円弧（`cap_side_pts`・`CAP_BAND`・`CAP_HORN`）。手が触れる所は角があるほうがよいので、丸い形はやめた
- 上面に片側 3 本の V 溝（`CAP_NOTCH`）、白いラインは 0.35 盛り上げる（`CAP_LINE_RAISE`）。境目は 0.3 面取り（`CAP_EDGE`、白いラインの角だけ 0.6）
- 幅 11.5、長さ 28、山の高さ 13.4、谷はレバーの上 1.6。パネルの上 4.5mm に浮かせ、レバーに 8.5 差し込みます
- 穴は段なしの 2.0×6.0＋すき間 0.2（`CAP_FIT`）。両端にレバーの横溝へはまる丸い爪（`CAP_SNAP`、かかり 0.25）。穴の壁と一体で、押せば入り引けば抜けます
- 底面を下にして AMS の 2 色で刷ります。毎層色が替わるので、5 個まとめて刷ると交換回数を分け合えます
- マット PLA は光を通しにくいので、白いラインの光り方が弱ければ芯だけ透明系の PLA / PETG にします

## ノブ（`knob_body` + `knob_line`）

ABS-28 と外形（Φ15×15.7）・底のくぼみ・軸穴の深さ（14.2）が同じ、印刷用のノブです。

- 側面は縦溝 30 本（`KNOB_KNURL`）、上面に深さ 0.6 の指示線を別の色で埋めます。上面を下にして刷るので、色替えは最初の 3 層だけ
- 軸穴（`KNOB_GRIP`）：入口は Φ6.2 の丸、奥の 8mm だけ 18 山の星形（山の先の内径 5.6）。山がローレットに食い込んで回りません。付け根は 45°（上を下に刷っても宙に浮かない）
- 軸は 18 山なので 20° 刻みでしか付きません。ボリュームを左に回しきってから、指示線が最小の目盛りに一番近い向きで差します。ずれが気になれば `KNOB_ROT` で目盛りごと回します

## STL をきれいに保つ

水密でない・面積 0 の三角が出たことがあり、面がぴったり重なる作り方をやめました。

- 天板は「溝より上の外形＋差し込み」の 1 つの塊から削るだけにする（部品を 0.01 重ねてつなぐ・彫りを埋め戻すのをやめた）
- 爪の返しは裏より下まで伸ばし、最後に裏の面でまとめて切る（壁と爪が裏の 1 本の線で出会わないよう 0.1 ずらす）
- 最後に、印刷の向きで底を水平な面で 0.001 切り直す（傾いたまま作って戻すと底に点が残った）
- ノブの溝は、上面と同じ高さで切ると閉じた空洞になったので、溝だけ上へ 0.5 抜いて切る

今は top_plate・bottom_case・nano_clip とも水密で面積 0 の三角はありません。ツマミと fit_test には曲面のつなぎ目に面積 0 の三角が残りますが、刷って問題なかったのでそのままです。

## 組み立て

1. スライダー本体を天板の裏のくぼみに押し込んで爪で留める（ゆるければ M2 皿ネジを上から）
2. ボリュームを裏の丸いくぼみに入れ、表からナットで留める
3. Nano を押さえと一緒に底ケースへ入れる
4. 天板を底ケースに押し込んでスナップで閉じる（足りなければ M3×8 を底の座ぐりから四隅へ）
5. ツマミとノブを差す
