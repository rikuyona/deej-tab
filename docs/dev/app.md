# PC アプリ（`app/`）

公式 deej の代わりに使う、Python の常駐アプリです。COM ポートは 1 つのプロセスしか開けず、deej と拡張機能向けの中継サーバーを別々に動かせないため、1 つにまとめて作り直しました。`config.yaml` の形式は deej と互換です。

## 構成

| ファイル | 役割 |
|---|---|
| `deej_tab.py` | 本体。シリアル受信・音量の計算・WebSocket サーバー・トレイ・設定画面のウィンドウ |
| `ui.html` | 設定画面（本体が配信する 1 枚のページ） |
| `leds.py` | LED の光り方の計算（ファームウェアと同じ）・数値の範囲・端の位置の検証 |
| `winsys.py` | Windows の部品（ショートカット・最前面のアプリ・全画面の判定） |
| `macsys.py` | Mac の部品（[mac.md](mac.md)） |
| `appcatalog.py` | 割り当てに出すアプリの一覧とアイコン（Windows） |
| `obs.py` | OBS 連携（obs-websocket v5） |

スレッド：シリアルの受信と音量の変更（`serial_thread`）、WebSocket と HTTP（asyncio）、最前面のアプリの確認（0.5 秒ごと）、ショートカット。設定画面は別プロセス（`deej-tab.exe --settings`）で、閉じてもトレイの本体は残ります。

### 外とのつながり

| 窓口 | 相手 |
|---|---|
| `GET http://127.0.0.1:8765/` | 設定画面（`ui.html`）。`/favicon.ico`・`/icon.png`・`/appicon/xxx.exe`（同じオリジンからだけ） |
| `GET /health` | 拡張機能の起動確認（200 を返す） |
| WebSocket `/` | Chrome 拡張機能（[extension.md](extension.md)） |
| WebSocket `/ui` | 設定画面。Origin が `127.0.0.1:8765` の時だけ受け付ける |

## config.yaml

exe の隣に置きます（Mac の .app は `~/Library/Application Support/deej-tab/`）。なければ初期設定で作り、保存されると自動で読み直します。設定画面から保存するとコメントは消え、先頭に説明が入ります。

deej と同じキー：`slider_mapping`・`invert_sliders`・`com_port`・`baud_rate`・`noise_reduction`。割り当て先 `master`・`mic`・`system`・`deej.current`・`deej.unmapped`・`xxx.exe`、グループ指定（1 本に複数）も同じです。

deej-tab で足したキー：

| キー | 内容 |
|---|---|
| `enabled` | `false` で一時停止 |
| `slider_options` | スライダーごとの `invert`・`max_volume`・`unity_position`・`glide` |
| `glide` | 音量がスライダーについてくるまでの秒数（全体） |
| `restore_on_pause` | 一時停止・終了で音量を元に戻す |
| `pickup` | プロファイルを切り替えた時に音量を飛ばさない |
| `hotkeys` | 一時停止のショートカット |
| `profiles`・`active_profile` | プロファイル（2 つ以上ある時だけ書く） |
| `slider_calibration` | スライダーの端の位置（生の値） |
| `device_id` | つないだコントローラーの ID |
| `led_mode`・`led_params`・`led_presets` | LED |
| `obs` | OBS 連携 |
| `language` | `auto` / `ja` / `en` |
| `websocket_port` | 既定 8765 |

`noise_reduction` には deej にない `none`（1% ごと）があります。ファームウェアの平均で揺れが 0 になり、「強」（3.5%）だとゆっくり動かした時に音量が飛び飛びになったためです。

## 音量の計算

```
生の値 → 端の位置で 0〜1 に直す（calibrated）→ 1% に切り捨て → 反転
       → 揺れの抑え（noise_reduction のしきい値以上変わった時だけ）
       → スライダーの位置を音量に直す（slider_volume）
       → ついてくる（glide）→ 割り当て先にかける（apply）
```

- **いちばん上の音量**（`max_volume`、10〜400%）と **100% になる位置**（`unity_position`、5〜95%）：下は 0〜100%、上は 100%〜上限の 2 本の直線。省略すると比例（200% なら 50% の位置）。前後 2% は 100% ちょうどに吸い付きます
- **100% を超える分は Chrome のタブと OBS だけに効きます**。Windows のアプリ・全体・マイクは API の上限が 100% です
- **反転**：スライダーごとの `invert` は全体の `invert_sliders` と足し合わせません（個別の指定があればそれだけ。二重反転で元に戻ることはない）。全体と同じ値にしたら個別の指定は消し、「すべて反転」を切り替えると個別の指定は全部消えてそろいます
- **ついてくる**（`glide`）：スライダーを速く動かしても、音量が目標へ指数的に近づきます（最初は速く、近づくほどゆっくり。秒数で 95%）。30ms ごとに少しずつかけます（`glide_tick`）。一時停止中は止まり、プロファイルを切り替えた時は今の音量から始めます
- 設定画面の表示にも揺れの抑えをかけます（`shown_levels`）。音量とピックアップの判定は揺れの抑え前の値のままです

### 音量の掛かり方

- Windows のアプリの音量は、全体の音量に対する割合です
- タブの実際の音量 ＝ タブのスライダー × Chrome のアプリの音量 × 全体の音量
- スライダーの値は位置の絶対値です（ノブの中央 ＝ 50%。基準からの相対ではない）

## 割り当て先

| 割り当て先 | 動き |
|---|---|
| `master` / `mic` | 既定の出力・入力デバイスの音量 |
| `system` | システム音（通知音など） |
| `xxx.exe` | そのアプリの全セッション |
| `deej.current` | いちばん手前のウィンドウのアプリ。ほかのスライダーに割り当て済みのアプリと、`tab.N` を使っている時の Chrome には触らない（Chrome 全体を変えるとタブ用スライダーの上限まで変わるため）。Chrome が最前面なら、表示中のタブだけを拡張機能に変えさせる |
| `deej.game` | 最後に全画面だったアプリ（ウィンドウがモニター全体を覆い、タイトルバーなし・最大化でない）。ほかのウィンドウが前に来ても、終了するまで操作し続ける（Discord のオーバーレイや Alt+Tab のため） |
| `deej.unmapped` | どのスライダーにも割り当てていないアプリ全部 |
| `tab.N` | 拡張機能で番号 N を付けたタブ（1〜6） |
| `obs:ソース名` | OBS の音声ソース |

同じ割り当て先は 1 本のスライダーにしか置けません（ほかにあれば移動）。割り当て先と番号は `valid_target` で検証し、知らない操作にはエラーを返します。

## 一時停止と元に戻す

- `enabled: false` で一時停止。設定画面のヘッダーのスイッチ・トレイ・ショートカットで切り替えます。一時停止中はメーターだけ動き、音量は変えません。トレイと拡張機能のアイコンは灰色になります
- 再開すると、今のスライダーの位置で全部かけ直します
- **元に戻す**（`restore_on_pause`、初期設定オン）：一時停止・終了した時に、アプリ・マイク・OBS の音量を deej-tab が最初に変える前の値に戻します。最初に変える時に元の値を覚え（`_remember`）、戻したら忘れて、再開後にまた覚え直します
  - **全体の音量は戻さず、そのままにします**。起動した時の 100% に戻ると、止めた瞬間に急に大音量になるためです（Mac の出力も同じ）
  - Chrome のタブはこの設定に関係なく、一時停止で元の音量に戻ります（終了時も）

## プロファイル

割り当て一式（`slider_mapping`・`slider_options`）に名前を付けて切り替えます。上の `slider_mapping` が使用中のプロファイルの中身で、`profiles` に写しを持ちます（1 つしかなければ `profiles` は書かない＝deej と同じ形）。

- 設定画面の上・トレイのメニュー・プロファイルごとのショートカットで切り替えます
- **自動切り替え**（`auto_apps`）：そのアプリが最前面に来たら切り替え、そのアプリが**終了したら**元に戻します（後ろに回っただけでは戻さない）。自動で切り替わった後に手で戻したら、そのアプリがいったん前から外れるまで自動では切り替えません
- **ピックアップ**（`pickup`、初期設定オン）：切り替えた直後、各スライダーは割り当て先の今の音量の位置を通るまで効きません（差が 3% 以内になるか、またいだら効く）。設定画面は緑の点線、LED は点滅で知らせます。今の音量がわからない割り当て先（最前面のアプリなど）は待ちません

## コントローラーをつなぐ

- `com_port` を開き、5 秒何も届かなければ開き直します（スリープ復帰後に開いたまま止まることがあるため）
- つないで 2.5 秒 ID が来なければ `@I` で聞きます（開いてもリセットされない Nano のため）。初めての ID は `device_id` に覚えます
- `com_port` のポートが消えていたら、USB のシリアルポートだけ（Bluetooth は開くと待たされるので除く）を順に開いて 3.5 秒読み、同じ ID のものにつなぎ直して `com_port` を書き換え、設定画面にお知らせを出します。ID がわからなければ（古いファームウェア）、6 本分の値を送ってくる最初のポートにします
  - ほかの Arduino を何度もリセットしないよう、USB のポートの顔ぶれが変わった時だけ探します
  - ポートがあるのに開けない時（ほかのアプリが使っている）は探しません

## スライダーの端の位置を合わせる

設定ページの「コントローラー」→「合わせる」で、各スライダーを上下の端まで動かして測ります。測っている間は音量を変えません。画面を閉じた時・切断した時も測るのをやめます。

- 保存すると `slider_calibration`（`0: [下端, 上端]`、生の値）に入ります。プロファイルを切り替えても変わりません
- 測った端から 8（`CAL_MARGIN`）だけ内側を 0% / 100% にします。0・1023 の近くまで届いていれば端そのものを使います
- 十分に動かしていないスライダー（範囲 300 未満・下端 > 400・上端 < 623、`leds.valid_calibration`）は前のままにします。端まで届いているスライダーは保存せず「合わせる必要はありません」と出します
- Nano は生の値を送り続けます（deej 互換）。アプリが `Config.calibrated()` で位置に直し、Nano にも `@C` で送って LED の判断（0 で消灯・位置で明るさ）に使わせます。操作したかどうかは生の値で見ます

## LED

`led_mode`：`off`（PC から指示しない）／`status`（状態を表示）／`meter`（音に合わせる）。形式は [hardware.md](hardware.md#pc-とのやりとり)。

- 状態：割り当て先が動いていない（`D`。タブ未割り当ての `tab.N` など）・0（`O`）・100% 超え（`B`）・ピックアップ待ち（`P`）
- 音に合わせる時は、割り当て先の音の大きさ（タブは拡張機能が測って送る）を 15 回/秒で送ります
- **光り方の設定**：設定ページの「LED の光り方」でプレビューを見ながら選びます。`led_params` には初期設定から変えたものだけ保存し、`@P` で Nano に送ります（`led_mode: off` でも送る）
  - 光り方ごとに数値を覚えます（`leds.STYLE_GROUPS`・`apply_change`）。切り替えると前に使っていた数値に戻り、初めての光り方は今の数値を引き継ぎます。`led_presets` に保存し、「初期設定に戻す」で消えます
- **プレビュー**：アプリの中の分身（`DeejTab.led_sim` ＝ `leds.LedSim`）が、Nano に送った行とスライダーの値を同じように受け取り、設定画面へ 20 回/秒で明るさを送ります。Nano がつながっていなければ PC なしの光り方を出します
- 書き込みが詰まる相手（受信を読まない古い仮スライダーなど）には、0.5 秒で諦めてその接続では LED の指示を送りません

## OBS 連携（`obs.py`）

- obs-websocket v5。割り当て先は `obs:ソース名` で、音声のあるソースだけ候補に出します
- 音量はタブと同じカーブ（100% までは 2 乗、超えた分はそのまま、OBS は 20 倍まで）
- パスワードは `config.yaml` に平文で保存します。パスワード違い（4009）はそう表示します

## ショートカット

`RegisterHotKey`（`winsys.py` の専用スレッド）。修飾キーなしは F13〜F24・Pause・ScrollLock だけ使えます。ほかのアプリが使っていれば設定画面に赤字で出します。

## 設定画面

- 本体が `http://127.0.0.1:8765/` で配信し、pywebview（Windows は Edge WebView2、Mac は WKWebView）の自前のウィンドウで開きます。pywebview がなければ Chrome / Edge のアプリウィンドウ（`--app`）で開きます
  - Chrome で開く時は専用のプロファイル（`%LOCALAPPDATA%\deej-tab\ui-profile`）を使います。普段の Chrome が起動中だと `--window-size` が無視されるためです
- ヘッダーで「ミキサー / 設定」の 2 ページに分かれます（`#settings` で設定ページ）。設定ページには、OBS につながらない・ショートカットを登録できない時に黄色い点が付きます
- タイトルバーは画面と同じ暗い色（DWM）。アイコンは `%LOCALAPPDATA%\deej-tab\icon.ico`
- 設定画面が開いていれば、トレイから開いても新しいウィンドウは出さず手前に出します。2 つ目の deej-tab を起動した時も、設定画面を開くだけで終わります。トレイから終了すると設定画面も閉じます
- メーターの塗りは実際の音量、つまみはスライダーの位置（目標）です。ついてくる途中はつまみが枠だけになり、塗りが追いかけます（`posOf` で音量 → 位置に直す）

### ウィンドウの大きさ

開いた最初の 1 回だけ、中身が切れないぎりぎりの大きさにして画面の中央に移します。

- 基準：名前は 2 行まで、「割り当てを追加」と見出しは 1 行、スクロールが出ない。幅は 1001 以上（狭いと 2 段になる）。幅 +40・高さ +16 の余裕を持たせる
- ミキサーのページで測ります。ページが必要な大きさを測り、自前のウィンドウなら `window.pywebview.api.fit`、Chrome なら `/ui` の `fit_window` で送ります。受けた側が Win32 でウィンドウを動かします（ページの `resizeTo` は最大化で開いた Chrome に効かなかった）
- ウィンドウの準備前に届いた頼みは取っておいて、出た時に合わせます（`SettingsApi._shown`）。ページ側は pywebview の窓口を最大 2 秒待ち、来なければ Chrome として頼みます
- 合わせた大きさは `%LOCALAPPDATA%\deej-tab\window.json` に覚え、次からは最初からその大きさで開きます

### 割り当ての追加（`appcatalog.py`）

音を出しているアプリ／起動中のアプリ（タスクバーに出るウィンドウ）／最近使ったアプリ（`%LOCALAPPDATA%\deej-tab\apps.json`）／インストール済み（スタートメニューのショートカット。Discord などの `Update.exe` 形式も解く）から選びます。検索・↑↓・Enter で選べ、自前のウィンドウなら「exe ファイルから選ぶ…」もあります。

- アイコンは exe から取り出して `/appicon/xxx.exe` で返します。複数スレッドで同時に取り出すとたまに失敗したので、1 つずつ順に行います

### 言語

- `language`：`auto`（Windows の表示言語。`GetUserDefaultUILanguage` が日本語なら ja、ほかは en）／`ja`／`en`。画面へは `options.language` と、auto を解いた `lang` を送ります
- `ui.html` は日本語で書き、英語の時は表示中の文字（テキスト・placeholder・title・aria-label・confirm）を `I18N_EN`（完全一致、空白は 1 つにまとめる）と `I18N_EN_RE`（数字や名前が入る文言）で置き換えます（`trText`・MutationObserver）。**文言を足したら `I18N_EN` にも英語を足します**。表にない文言は日本語のまま出ます
- 英語 → 日本語は元の文言を持っていないので読み直します。最後に使った言語は localStorage に覚えて、読み込み直後から使います
- 訳さないもの：ユーザーが付けたプロファイル名（初期の「標準」だけは Standard と出る）、COM ポートの名前、「日本語」
- タスクトレイは `TEXT_EN`・`tr()`。メニューは開くたびに作るので、言語を変えるとすぐ反映されます。ログは日本語のままです

## タスクトレイと自動起動

- pystray で常駐します。クリックで設定画面、右クリックで一時停止・プロファイル・自動起動・終了
- トレイのアイコンは、コントローラーがつながっていない間つまみが灰色になります。ツールチップに接続先と状態を出します
- 自動起動は HKCU の Run に登録します（`--tray` は設定画面を開かない）。exe を起動した時に Python 版のまま登録されていたら、exe に付け替えます

## アイコン

`deej_tab.py` の `app_icon()` で描きます（スライダー 3 本・赤いつまみ・LED の光）。exe（16〜256px）・トレイ・設定画面のファビコンとロゴ・拡張機能（`tools/make_ext_icons.py`）で同じ絵です。24px 以下は線を太くして飾りを省き、48px 以上だけ光・つや・指示線を付けます。

## exe（`build.py`）

- PyInstaller の onefile・windowed。`config.yaml` とログは exe の隣、`ui.html` は exe の中です
- バージョン情報（プロパティ・タスクマネージャーに「deej-tab 音量ミキサー」）。番号は `VERSION`
- 入れておかないといけないもの：`--hidden-import pystray._win32`、`--collect-submodules serial.urlhandler`（`socket://` の仮スライダー用）
- exe から自分（設定画面）を起動する時は `PYINSTALLER_RESET_ENVIRONMENT=1` を渡します。渡さないと親の展開フォルダを使い回し、親が先に終わると `_overlapped` がないと言って落ちます
- 起動時、パッケージが import できれば pip を飛ばします。WMI が固まると、pip が OS の情報を取るところで無言のまま止まるためです
- websockets のログは警告以上だけ残します（拡張機能の `/health` 確認のたびに記録されていたため）

| ファイル | 内容 |
