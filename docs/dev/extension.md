# Chrome 拡張機能（`extension/`）

タブに番号（1〜6）を付け、deej-tab から届いた音量をそのタブにかけます。Manifest V3、Chrome 116 以降。

| ファイル | 役割 |
|---|---|
| `background.js` | Service Worker。deej-tab との通信・割り当て・ショートカット・右クリックメニュー・バッジ |
| `offscreen.html` / `offscreen.js` | タブの音声をキャプチャしてゲインをかける（方式 Y） |
| `content-media.js` | ページ内の動画・音声の音量を直接変える（方式 X） |
| `popup.*` | ツールバーのポップアップ（割り当ての一覧と今の音量） |
| `i18n.js`・`_locales/` | 文言 |

## 音量の変え方

| 方式 | 中身 | 向き不向き |
|---|---|---|
| **Y：タブの音をまとめて調整**（初期設定） | `tabCapture` でタブの音声を取り、Web Audio のゲインをかけて出す | 0 でしっかり無音。100% を超えられる。再読み込みしても続く |
| X：ページ内の動画の音量を変える | `<video>` / `<audio>` の `volume` を直接変える | Web Audio や DOM の外の音には届かず、0 でもかすかに聞こえるサイトがある |

方式 Y を基本にし、X はポップアップで切り替えられるように残しています。

- 音量のカーブ：100% までは音量の 2 乗（`CURVE_POWER`。B カーブのスライダー前提）、超えた分はそのままの倍率（200% ＝ 2 倍）。方式 X は 1 まで
- 方式 Y は 100% を超える時だけリミッター（WaveShaper の柔らかい頭打ち、0.9 から）を通します。100% 以下では通さないので音は変わりません
- 方式 Y で別の番号へ移す時は、キャプチャを取り直さずに移します（offscreen の `capture-move`）
- 方式 X のスクリプトは、拡張機能が消えたり再読み込みされたりしたら（Port の切断で検知）、元の音量に戻して止まります

## 割り当て

- **Alt+Shift+A**：このタブを空いている一番小さい番号へ。押すたびに次の空きへ移り、最後の次は解除（ほかのタブが使っている番号は飛ばす）。空きがなければバッジに「満」
- **Alt+Shift+1・2**：番号を指定して割り当て、もう一度押すと解除。3〜6 は `chrome://extensions/shortcuts` で割り当て（Chrome が初期設定で付けられるショートカットは 4 つまで）
- **Alt+Shift+D**：ポップアップを開く
- ページの右クリック →「deej タブ音量」からも割り当て・解除できます
- バッジ：割り当てたタブは番号、deej-tab の設定にない番号は「?」、割り当てられないページ（`chrome://` やウェブストア）は「!」
- 割り当てと方式はメモリに持ち、変わった時だけ保存します。変更は 1 つずつ順に処理します（`serial`）。Service Worker の起動時に、閉じたタブ・終わったキャプチャの割り当てを外します（`reconcile`）

## ポップアップ

- 配色は設定画面と同じ暗い色。番号は設定画面と同じ「タブ N」と出し、音量バーと値をリアルタイムに出します（Port で送る）
- ほかのタブに割り当て済みの番号は、タイトルのクリックでそのタブへ移動、× で解除、「入れ替え」でこのタブに替えます
- 一時停止中と 100% 超え（オレンジ）を表示します
- Chrome のエラーはわかる言葉にして出します（`background.js` の `explain`）

## deej-tab との通信

- deej-tab が起動していない時は、先に `GET /health` を確かめてから WebSocket を開きます（`chrome://extensions` に接続エラーが溜まらないように）
- deej-tab → 拡張機能：番号ごとの音量、`current`（表示中のタブ）、`enabled`（一時停止）、`lang`（言語）
- 拡張機能 → deej-tab：割り当て済みの番号（LED の「動いていない」表示に使う）、LED を音に合わせる時だけタブの音の大きさ（offscreen で測る）
- 一時停止中はタブを元の音量（ゲイン 1、方式 X は元の音量）に戻します

### 「今使っているアプリ」で Chrome が最前面の時

deej-tab から `current` が届いたら、最後に触ったウィンドウの表示中のタブを方式 X で変えます（方式 Y はタブごとにクリックが要り、自動ではキャプチャできないため）。

- 番号を割り当て済みのタブには触りません。あとで番号を割り当てたら、下げた分は戻します

## 文言

- ポップアップ・右クリックメニュー・アイコンの説明・エラーは `i18n.js`（`I18N.ja` / `I18N.en`、`t(key, ...)`）。deej-tab がつないだ時と言語を変えた時に送る `lang` を `storage.local` に覚えて使います。まだ届いていなければ Chrome の表示言語
- 拡張機能の名前とショートカットの説明は `_locales`（Chrome の表示言語。既定は en）
- `popup.html` は `data-i18n`（文字）・`data-i18n-html`（太字入り）・`data-i18n-aria`

## アイコン

`app_icon()` と同じ絵を `tools/make_ext_icons.py` で `extension/icons/` に書き出します。deej-tab が起動していない間は灰色のつまみになります。
