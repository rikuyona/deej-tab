# スライダー基板（基板版）

スライダー 5 本とノブを 1 枚の基板に載せ、Nano とはケーブル 3 本（JST ZH の電源 3 ピン・LED 6 ピン・信号 6 ピン）でつなぐ版です。
配線版（スライダーごとに線を引き回す）の改良版で、Nano・USB-C の位置とファームウェアはそのまま使えます。
部品はすべてスルーホールで、手でハンダ付けします（JLCPCB には基板だけを頼む）。

> **実物で確認済みです（2026-10-08）。** 発注した基板を組み立てて、スライダー 5 本・ノブの値と LED 5 個が動くこと、天板・基板・部品が合うことを確かめました。ノブのボリュームは、**配線版と同じ SH16K4 の端子の曲がりを伸ばして使います**（基板用として選んだ JH16K6 は、端子が v0.1.0 の長穴に最後まで入らなかった。下の「ボリュームの端子」）。ガーバーは Releases の `pcb-v0.1.0` にもあります。

- 基板：`deej-tab-sliders.kicad_pcb`（KiCad 10 で開ける）
- 作り直し：`"%LOCALAPPDATA%\Programs\KiCad\10.0\bin\python.exe" make_pcb.py`
  - 部品の配置と信号の割り当てはスクリプトで決め、線は自動配線（Freerouting 2.4.1）に引かせる（30 秒ほど）。GND は自動配線から外し、表裏のベタでつなぐ
  - 要るもの（`%LOCALAPPDATA%\deej-tab\tools`）：`freerouting-2.4.1.jar` と、Java 25 の zip 版（Eclipse Temurin JRE 25 を展開した `jdk-25...-jre`）。インストールは不要
  - `out/deej-tab-sliders-gerber.zip`：JLCPCB に出すガーバー一式
  - `out/deej-tab-sliders-bom.csv`：買う部品の一覧
  - `out/drc.txt`：KiCad の DRC の結果（エラー 0。残りは自作の部品形状がライブラリにない旨の警告だけ）
  - `out/deej-tab-sliders-top.svg` / `-bottom.svg`：表・裏の図
  - `outline.json`：基板の外形・コネクターと部品の位置（`case.py --pcb` が読む）
- ケース：`case\.venv\Scripts\python case\case.py --pcb` → `case/out/pcb/`
  - 配線版の底ケースを持っていれば、刷り直さずに使える。基板版の天板は 1.8mm 薄いので、四隅の柱に `spacer.stl`（厚さ 1.8mm の輪 4 個）を載せる。四隅を M3 で締めるなら M3×10

## 基板の中身

| 部品 | 型番 | 数 | 置き場所 |
|---|---|---|---|
| スライダー | Bourns PTL60-15R0-103B2（今と同じ） | 5 | 表（ハンダは裏） |
| ノブのボリューム | **SH16K4B103L20KCCI**（配線版と同じ。10kΩB。端子の曲がりを伸ばして長穴に挿す） | 1 | 表（パネルにナットで留める） |
| LED の抵抗 | カーボン抵抗 1/4W **150Ω**（足の間隔 10.16mm で寝かせる） | 5 | 裏（ハンダは表）。スライダーのすき間 |
| ノイズ対策 | 積層セラミックコンデンサー 0.1µF 50V **RD15F104Z1HL2L**（秋月 104065、10 個入り）各摺動子と GND の間 | 6 | 裏（ハンダは表） |
| 5V | 積層セラミックコンデンサー 10µF 25V **THD30E-1E106Z**（秋月 100464、足の間隔 5mm） | 1 | 裏（ハンダは表） |
| Nano へのコネクター | JST ZH 横向き **S3B-ZR-3.4**（JP）と **S6B-ZR-3.4**（JL・JA）（1.5mm、秋月） | 1＋2 | 裏（ハンダは表） |

- **LED の抵抗 150Ω**：赤 LED（Vf 1.8V、データシートの条件 20mA）に約 19mA。配線版の 330Ω（約 8.5mA）の約 2.2 倍の明るさ。5 個で約 95mA で、Nano（1 ピン 20mA 推奨）の範囲。これより下げると LED の 20mA を超える
- 基板の表はスライダー本体と天板（すき間 0.5mm）でふさがるので、抵抗・コンデンサー・コネクターの本体は裏に置き、表に出るハンダは天板の裏を 3mm 彫って逃がしている
- 基板：2 層・1.6mm・外形 100×100mm 以内（JLCPCB の最安枠）。Nano の真上は切り欠いてあり、Nano にハンダ付けする線の邪魔をしない
- ボリュームは今と同じくナットでパネルに留める（パネルの穴・回り止め・印刷のノブ・目盛りは配線版と同じ）。本体は取付面から 9.3mm とスライダー（7.0mm）より深いので、基板の左奥を切り欠いて本体を通す。端子を軸と平行に後ろへ伸ばし、基板の**長穴**（3.3×0.9mm）に通してハンダ付けする（SH16K4 は端子の V 字の曲がりを伸ばす。[ボリュームの端子](#ボリュームの端子)）
- 配線：自動配線（信号は主に裏、表はほぼベタ GND）。表裏ともベタ GND
- スライダーは今と同じ位置（22mm 間隔、ケースの X = 19 / 41 / 63 / 85 / 107）。端子は 4 本の列を手前にして上から見て左から 2・1・L・E（実物で確認済み）。ノブも同じ位置（19, 106）

## ケーブル（JP・JL・JA → Nano）

電源・LED・信号で 3 本に分けている。秋月のコネクター付コード（ZH 相当、片側ハンダメッキ）をそのまま挿し、ハンダメッキの側を Nano に付ける。1 番は四角いパッド。

- **JL（LED）と JA（信号）は Nano のすぐ左に縦に並び、口は Nano 向き（右）**。端子の並びは Nano の端子と同じ前後の順なので、コードはまっすぐ右へ出して、そのまま隣の Nano の端子に付けられる。1 番は奥の端
- **JP（電源）はボリュームの近く、口は手前**。コードは基板の下を手前へ出して、Nano の手前の端の 5V・GND へ

| コネクター | コード | 番号 | 信号 | Nano の端子 |
|---|---|---|---|---|
| JP 電源（3 ピン） | 3P 黒白赤（秋月 118272） | 1 | GND | GND（D 側） |
| | | 2 | +5V | 5V（A 側） |
| | | 3 | GND（予備） | 付けなくてよい |
| JL LED（6 ピン） | 6P(H) 白赤黒青黄緑（秋月 105719） | 1（奥） | D10 | D10（スライダー 5 の LED） |
| | | 2 | D9 | D9（スライダー 4） |
| | | 3 | D6 | D6（スライダー 3） |
| | | 4 | D5 | D5（スライダー 2） |
| | | 5 | D3 | D3（スライダー 1） |
| | | 6（手前） | 空き | 付けない |
| JA 信号（6 ピン） | 6P(H) 白赤黒青黄緑（秋月 105719） | 1（奥） | A0 | A0（スライダー 1） |
| | | 2 | A1 | A1（スライダー 2） |
| | | 3 | A2 | A2（スライダー 3） |
| | | 4 | A3 | A3（スライダー 4） |
| | | 5 | A4 | A4（スライダー 5） |
| | | 6（手前） | A5 | A5（ノブ） |

- JA のコードは Nano の A 側（A0 が奥、A5 が手前）、JL のコードは D 側の D10・D9・D6・D5・D3 に、それぞれ真横へ付ける
- **コードの色と番号の対応は、Nano に付ける前に確かめる**（基板に挿して、テスターで基板の端子とコードの先の導通を見る）。コネクターは向きが決まっているので挿し間違いはない。1 番の位置はデータシートの図から読んだもの
- コードは 20cm あるので、Nano までの長さに切ってから付ける（JA・JL は数 cm、JP は 10cm ほど）
- ファームウェア・アプリは今のまま（ピンの割り当ては配線版と同じ）

## 組み立て

1. 抵抗・コンデンサー・JP・JL・JA を**裏から挿して表でハンダ付け**し、表に出た足は短く切る
   - コンデンサーは基板に押し付けて付ける（裏の部品と底ケースの床のすき間はいちばん狭い所で約 2mm）
   - 抵抗は寝かせて付ける
2. ボリューム（SH16K4）の 3 本の端子の V 字の曲がりをラジオペンチで伸ばし、まっすぐ後ろ（軸と平行）へ向ける。3 本の間隔（5mm）がそろうようにする
3. 天板に、スライダーを表から M2 皿ネジ（**M2×4、10 本**）で、ボリュームをナットで留める。基板版は本体の下に基板があるので、配線版の爪はない
4. 基板を裏からかぶせる（スライダーの端子とボリュームの 3 本の端子が穴に入る。入りにくいときはボリュームの端子の向きを少し直す）
5. 裏からスライダーとボリュームをハンダ付けする（パネルに合った位置で固まる）。ボリュームの端子が長く出たら、ハンダのあと短く切る
6. コードを JP・JL・JA に挿し、Nano へ。天板を底ケースに閉じる
   - コネクターは奥まで挿す。半挿しになりやすく、半挿しだとスライダーの値がおかしくなる

## ボリュームの端子

基板は、ボリュームの取付面（パネルの裏）から 7.0〜8.6mm 後ろにあります（スライダーの高さで決まる）。ボリュームの端子は、ここまで軸と平行に伸びて、長穴（3.3×0.9mm、`make_pcb.py` の `POT_SLOT`）を通る必要があります。寸法はデータシート（秋月の PDF）の図の線の座標から測りました。

### SH16K4B103L20KCCI（使う方）

- 端子は本体の前寄りから外へ出て、V 字に折り返して後ろへ伸びるはんだ付け用の板。先は幅 3.0mm・穴 1.5mm、根元は幅 1.6mm、厚さ 0.49mm、軸の中心から約 12.7mm
- 曲げたままだと先は取付面の約 6.3mm 後ろまでで、基板（7.0mm）に届かない。**V 字の曲がりを伸ばしてまっすぐにすると、先は約 10.9mm 後ろまで届き、基板を貫通して裏に約 2mm 出る**。長穴を通るのは先の幅 3.0mm・厚さ 0.49mm の所で、すっと入る（実物で確認）
- 配線版と同じ部品なので、パネルの穴・回り止め・ノブはそのまま

### JH16K6B103L20KC-H13（基板用。最初に選んだ方）

- データシート（秋月の `JH16K6B103L20KC-H13.pdf`、縮尺 2:1 の図の線から測った）：端子は軸の中心から 13mm・5mm 間隔で、取付面の 3.5〜13.3mm 後ろまで軸と平行に伸びる板。**幅 3.0mm・厚さ 0.5mm**、本体より後ろの先 4.0mm だけ細い（基板に挿す時用の Ø1.2 の穴に合う太さ）。寸法の書いていない所の公差は「10 以下 ±0.3・10〜100 ±0.5」なので、幅は最大 3.3mm、軸からの距離は 13±0.5mm になり得る
- 基板（取付面の 7.0〜8.6mm 後ろ）は、幅の広い所を通る。基板の位置はスライダーの高さで決まるので、ケースの側では合っている（切る前の端子の先から底ケースの床まで約 7mm）
- **v0.1.0 の長穴 3.3×0.9mm（`make_pcb.py` の `POT_SLOT`）は狭い**：めっきで 0.1mm 前後細くなるので、幅 3.0mm（公差で 3.3mm）の板は入らないことがある。実物では先の細い所だけ入り、幅の広い所で止まった
  - v0.1.0 の基板で組む時：端子の幅の広い所のうち、本体の後ろの面から手前 3mm ほど（基板が通る所。取付面の 6.3〜9.3mm 後ろ）を、ニッパーかやすりで 2.8mm くらいまで細くしてから挿す
  - 直すなら：長穴を 4.0×1.2mm ほどに広げる（幅 3.3＋間隔の公差、厚さ 0.5＋軸からの距離の公差に、めっきの分を足す）。奥の端子のパッドが基板の奥の縁に近いので、パッドの大きさと外形の見直しも要る
