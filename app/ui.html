コントローラー

接続先コントローラーをつないだ USB の COM ポート
すべてのスライダーの向きを反転上げると音が小さくなるときはオン。1 本ずつ変えるときは各スライダーの ⚙ から
スライダーの端の位置を合わせるいちばん下・いちばん上まで動かしても 0% / 100% にならないときに。合わせた範囲はコントローラーにも保存され、LED も同じ範囲で動きます
揺れの抑え触っていないのに音量が小刻みに変わるときは強くします。強いほど、ゆっくり動かしたときに音量が飛び飛びに変わります
LED で知らせること割り当て先がない・100% を超えている・一時停止中などを、スライダーの LED の光り方で知らせます（専用のファームウェア deej-6ch-led が必要）
Windows の起動時に自動で起動タスクトレイに常駐します

LED の光り方

プレビューコントローラーの LED と同じ光り方です
操作していないとき明るさや速さは、光り方ごとに覚えます
起動したときコントローラーをつないだとき。速さは光り方ごとに覚えます
操作したときスライダーを動かしたとき。明るさや時間は、光り方ごとに覚えます
詳しい設定（状態を知らせるときの光り方など）
初期設定に戻す変えた設定はコントローラーにも保存され、PC から外しても同じ光り方になります

動作

音量の変わり方スライダーを速く動かしたとき、音量がどのくらいかけて追いつくか。1 本ずつ変えるときは各スライダーの ⚙ から
一時停止・終了したら音量を元に戻すWindows・OBS の音量を、deej-tab が変える前に戻します（Chrome のタブはいつも元に戻ります）
プロファイルを切り替えても音量を飛ばさない切り替えたあと、スライダーが今の音量の位置（緑の点線）を通るまで音量を変えません
一時停止のショートカットどのアプリを使っていても効きます。Backspace で解除

OBS 連携

OBS の音声ソースをスライダーで操作OBS の [ツール] → [WebSocket サーバー設定] で「WebSocket サーバーを有効にする」をオンにしてください。割り当ての追加に「OBS の音声ソース」が出ます
ポート・パスワードOBS の WebSocket サーバー設定と同じもの。パスワードは config.yaml にそのまま保存されます
